Declarative

The same app built six ways: a label and an Ok button. Clicking Ok changes the state, and the label changes to "CLICKED".

  1. imperative: build the DOM tree with code
  2. declarative-html: describe the tree with HTML
  3. declarative-string: describe the tree with an HTML string
  4. declarative-htm: HyperScript Tagged Templates (htm) with Preact
  5. declarative-h: hyperscript h() calls with Preact
  6. declarative-jsx: JSX with Preact
